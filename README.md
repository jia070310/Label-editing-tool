# 标签编辑打印工具

桌面端标签设计与打印工具（Electron），按毫米尺寸精确输出，无浏览器页眉页脚。

## 启动（推荐）

在项目目录 `d:\项目\标签打印` 打开终端：

**PowerShell（若提示禁止运行脚本，用下面这条）：**

```bat
npm.cmd run desktop
```

**或 CMD / 已允许脚本的 PowerShell：**

```bash
npm run desktop
```

会打开桌面窗口（编辑界面 + 精确打印）。

## 仅前端预览（调试用）

```bash
npm run dev
```

浏览器模式仅用于调试界面，正式打印请用 `npm run desktop`。

## 主要功能

- **新建模板**：按宽度/高度（mm）创建空白标签
- **表格**：增减行列、合并/拆分、行高列宽、双击编辑
- **拖拽**：移动、缩放元素
- **元素**：文本、矩形、线条、条码、二维码、日期、警示语
- **打印**：桌面端按标签毫米尺寸输出，关闭页眉页脚
- **保存**：本地模板列表（localStorage）

## 表格操作

1. 左侧点「表格」添加
2. 拖橙色控制点调整大小
3. **Ctrl + 点击**多选后合并
4. 双击单元格编辑
5. 右侧属性面板改行列/行高/列宽
